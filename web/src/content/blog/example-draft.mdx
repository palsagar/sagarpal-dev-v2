## The equations

Two chemical species share a grid. Species $u$ is fed in at rate $F$, species $v$ is removed at rate $F + k$, and the reaction $u + 2v \to 3v$ converts one into the other:<Sidenote>Every value on this site uses the scaling from Karl Sims's tutorial: $D_u = 1$, $D_v = 0.5$ and a time step of one.</Sidenote>

$$
\frac{\partial u}{\partial t} = D_u \nabla^2 u - u v^2 + F (1 - u) \tag{1}
$$

$$
\frac{\partial v}{\partial t} = D_v \nabla^2 v + u v^2 - (F + k)\, v \tag{2}
$$

Written out on the grid, with the nine-point stencil and an explicit Euler step, one update of $u$ at cell $(i, j)$ is long enough to need sideways scrolling on a phone:

$$
u_{i,j}^{n+1} = u_{i,j}^{n} + \Delta t \left[ D_u \left( -u_{i,j} + 0.2 \left( u_{i\pm1,j} + u_{i,j\pm1} \right) + 0.05 \left( u_{i\pm1,j\pm1} \right) \right) - u_{i,j} v_{i,j}^2 + F \left( 1 - u_{i,j} \right) \right] \tag{3}
$$

## On the GPU

Each cell reads its eight neighbours and writes one value, so the update maps directly to a fragment shader. The state lives in two float textures, and each step reads one and writes the other:

```glsl title="step.frag"
void main() {
  vec2 s = texture(uState, vUv).rg;               // u in red, v in green
  vec2 lap = laplacian(vUv);                      // nine-point stencil
  float r = s.r * s.g * s.g;
  float du = 1.0 * lap.r - r + uFk.x * (1.0 - s.r);
  float dv = 0.5 * lap.g + r - (uFk.x + uFk.y) * s.g;
  outState = vec4(s + vec2(du, dv), 0.0, 1.0);    // dt = 1, Karl Sims scaling
}
```

<Callout title="Keep both species in one texture">
  Storing $u$ and $v$ in two channels of the same texture halves the texture
  reads in the stencil, and swapping buffers stays a single pointer flip.
</Callout>

A reference version in NumPy is useful for checking the shader:

```python
import numpy as np

def step(u, v, F, k, du=1.0, dv=0.5):
    lap = lambda a: (-a + 0.2 * sum(np.roll(a, s, (0, 1)) for s in [(1, 0), (-1, 0), (0, 1), (0, -1)])
                     + 0.05 * sum(np.roll(a, s, (0, 1)) for s in [(1, 1), (1, -1), (-1, 1), (-1, -1)]))
    r = u * v * v
    return u + du * lap(u) - r + F * (1 - u), v + dv * lap(v) + r - (F + k) * v
```
